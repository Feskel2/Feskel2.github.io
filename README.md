# FIB · NSB — база и каф

Сайт-памятка для новых сотрудников **FIB · NSB** на Majestic RP (Phoenix): карта знаний, процедура задержания по шагам, статьи УК с санкциями, чек-лист и подробная инструкция.

**Сайт:** https://feskel2.github.io/  (зеркало: https://feskel2.github.io/fibnsb/)
**Инструкция:** https://feskel2.github.io/guide.html

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | интерактивная карта: 8 веток, 54 узла + вкладки «Каф по шагам», «Статьи», «Чек-лист» |
| `guide.html` | подробная инструкция: тайминги кафа, скрипты `/me` и `/do`, деревья решений, документы, план на 7 дней |
| `manifest.webmanifest`, `icon.svg` | установка на главный экран телефона (PWA-манифест) |

Прогресс изучения и отметки чек-листа хранятся в `localStorage` браузера — на сервер ничего не уходит.

## Важно

Неофициальная памятка. Устав фракции и регламент NSB главнее сайта: где расходится — прав устав. Номера статей и сроки на других серверах Majestic отличаются — сверяй свою редакцию кодексов.

## Правки

Сайт — статические файлы, без сборки. Правишь `index.html` / `guide.html`, коммитишь в `main` — GitHub Pages обновляет страницу в течение минуты.
